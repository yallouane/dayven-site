Questions fréquentes

Comment résilier mon abonnement ?
L’abonnement est géré par Apple : Réglages iOS → ton nom → Abonnements → Dayven → Résilier. L’accès reste ouvert jusqu’à la fin de la période déjà payée.

Comment retrouver mon abonnement sur un nouvel iPhone ?
Dans l’app, sur l’écran d’abonnement : « Restaurer les achats », avec le même identifiant Apple.

Où sont mes données ?
Sur ton iPhone, et dans ton iCloud privé si tu l’as activé. Il n’y a pas de compte Dayven. Supprimer l’application efface l’agenda de l’iPhone ; les données iCloud se gèrent depuis Réglages iOS → ton nom → iCloud.

Que voit l’assistant ?
Ta phrase et les activités concernées, le temps de te répondre. Rien n’est conservé sur nos serveurs. Détails dans la politique de confidentialité.

Les rappels n’arrivent pas.
Vérifie que les notifications sont autorisées pour Dayven dans Réglages iOS → Notifications, et que l’activité a bien un rappel dans sa fiche.

Les widgets restent vides.
Ouvre Dayven une fois après avoir posé le widget : l’app partage alors ta journée avec lui.
